# Лабораторная №2: оплата регистрации токенами MMMSIS

Два смарт-контракта реализуют регистрацию в сервисе за **67 MMMSIS**. Токен используется как внутренняя расчётная единица для доступа к образовательным мероприятиям и материалам.

Цель: интегрировать ERC-20 и использовать собственный токен для оплаты услуги вместо ETH.

## Токен и сервис

| Контракт | Назначение |
|---|---|
| `MMMsisToken.sol` | ERC-20 на OpenZeppelin 5.0.2. Название: `MMMsis token`, символ: `MMMSIS`, эмиссия: 2026, точность: 18 знаков |
| `MMMsisAccess.sol` | Регистрация за 67 MMMSIS с переводом оплаты владельцу сервиса |

Токен поддерживает `name`, `symbol`, `decimals`, `totalSupply`, `balanceOf`, `transfer`, `approve`, `allowance`, `transferFrom`. Дополнительный выпуск не предусмотрен.

Сервис предоставляет `register()` и `isRegistered(address)`. Для списания используются `IERC20` и `SafeERC20`, для защиты от повторного входа используется `ReentrancyGuard`.

## Как проходит оплата

1. Аккаунт №0 переводит аккаунту №1 **67 MMMSIS** через `transfer`.
2. Аккаунт №1 разрешает сервису списать **67 MMMSIS** через `approve`.
3. Аккаунт №1 вызывает `register()`. Сервис вызывает `transferFrom`, переводит оплату владельцу и сохраняет регистрацию.

При недостаточном балансе или разрешении операция отменяется. Повторная регистрация запрещена. События: `Transfer`, `Approval`, `Registered`.

**Услуга оплачивается MMMSIS, газ оплачивается тестовым ETH Ganache.** Вызов регистрации имеет `value = 0`; в сервисе нет `payable` и `msg.value`.

## Запуск

Требуются Node.js 20, Python 3.14, uv и Ganache. Параметры сети: RPC `http://127.0.0.1:7545`, Network ID `5777`, Chain ID `1337`, hardfork Merge.

Установка зависимостей из корня репозитория:

```bash
cd lab2
export PATH="$PWD/../lab1/.tools/node/bin:$PATH"
npm install --save-exact @openzeppelin/contracts@5.0.2
npm install --save-dev --save-exact truffle@5.11.5
uv venv --python 3.14
uv pip install --python .venv/bin/python web3==8.0.0 pytest==9.2.0
```

Компиляция, развёртывание и демонстрация при запущенном Ganache:

```bash
npx --no-install truffle compile
npx --no-install truffle migrate --network development
.venv/bin/python demo_registration.py --check
.venv/bin/python demo_registration.py
```

Solidity 0.8.20 компилирует контракты для EVM `paris`. Миграция создаёт оба контракта и передаёт сервису адрес токена. Python загружает ABI и адреса из `build/contracts/`.

Режим `--check` только читает состояние. Повторный запуск завершённой демонстрации не отправляет транзакции. После прерывания скрипт продолжает с незавершённого этапа.

## Тесты

```bash
.venv/bin/python -m pytest -q --tb=short
```

**Все 25 тестов пройдены.** Проверяются эмиссия, переводы, разрешения, оплата, события, запрет повторной регистрации и отказ при ошибочных условиях. Отдельно проверены отклонение ETH и отсутствие повторных транзакций при перезапуске демонстрации.

Каждый тест создаёт отдельные контракты и не меняет состояние основной демонстрации.

## Стандарты

| Стандарт | Назначение |
|---|---|
| [ERC-20](https://eips.ethereum.org/EIPS/eip-20) | Взаимозаменяемые токены. Подходит для оплаты в MMMSIS |
| [ERC-721](https://eips.ethereum.org/EIPS/eip-721) | Уникальные токены, NFT. Каждый имеет собственный идентификатор |
| [ERC-777](https://eips.ethereum.org/EIPS/eip-777) | Взаимозаменяемые токены с операторами и хуками отправки и получения. Хуки требуют защиты от повторного входа |
| [ERC-1155](https://eips.ethereum.org/EIPS/eip-1155) | Несколько типов токенов в одном контракте |
| [BRC-20](https://domo-2.gitbook.io/brc-20-experiment) | Токены Bitcoin на основе записей Ordinals, учитываемых индексаторами |

## Материалы

Исходники находятся в `contracts/`, миграция в `migrations/`, тесты в `tests/`. Python-код: `demo_registration.py` и `lab_client.py`. Конфигурация Truffle: `truffle-config.js`.

Для демонстрации в Ganache нужно добавить `lab2/truffle-config.js` в Truffle Projects. Скриншоты: создание контрактов, `transfer`, `approve`, `register` с событиями оплаты, итоговые балансы и результат тестов.

Цена и получатель оплаты фиксированы. Возврат оплаты и отмена регистрации не предусмотрены.
